## 🚀 СЛЕДУЮЩИЕ ШАГИ

### 1. Протестируй приложение локально
```bash
npm run dev
```

Проверь:
- Авторизация работает (старые пароли должны работать)
- Товары отображаются
- Заказы видны в админке
- Изображения загружаются (если они в Storage, нужно сначала мигрировать файлы)

### 2. Мигрируй Storage файлы (если нужно)
```bash
# Создай .env.migration с ключами
node migrate-storage.js
```

### 3. Обнови Vercel (если используешь)
1. Зайди в [Vercel Dashboard](https://vercel.com)
2. Выбери проект
3. Settings → Environment Variables
4. Обнови все Supabase переменные на новые значения
5. Redeploy проект

### 4. Удали старый проект (опционально)
Через 7 дней неактивности старый проект заснет anyway, но можешь удалить его вручную через Dashboard если уверен что всё работает.
